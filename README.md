# نستكمل — نسخة GitHub Pages التجريبية

هذه نسخة واجهة تفاعلية ثابتة من منصة «نستكمل»، صُممت لتعمل مباشرة من متصفح الهاتف أو الكمبيوتر.

## النشر على GitHub Pages

1. أنشئ مستودع GitHub عامًا باسم `nastakmil-demo` (أو أي اسم مناسب).
2. ارفع ملف `index.html` و `.nojekyll` في جذر المستودع. (ويمكن إرفاق README).
3. من Settings → Pages، اختر **Deploy from a branch**، ثم `main` و `/(root)`، واحفظ.
4. عند اكتمال النشر يظهر رابط داخل Settings → Pages على النمط `https://USERNAME.github.io/nastakmil-demo/`. هذا مثال لصيغة الرابط، وليس رابطًا حقيقيًا حتى يتم النشر.

## هام

- نسخة واجهة تجريبية فقط، وليست نظام شركات مكتملًا.
- البيانات محفوظة محليًا داخل متصفح المستخدم عبر localStorage، ولا تتزامن بين الأجهزة.
- لا يوجد تسجيل دخول حقيقي، ولا رفع أو حفظ فعلي للصور والملفات (تُعرض أسماؤها فقط).
- لا تستخدم بيانات شركات فعلية أو سرية.
